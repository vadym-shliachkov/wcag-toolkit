# 3.3.7 Redundant Entry

WCAG 2.2 · Level **A**

A practical summary in our own words; the exact obligations are set by the normative text and its definitions.

## Applicability

Information was previously entered by or provided to the user and is required again in the same process.

## What is required

Auto-populate it or let the user select the previously entered information.

## How to test

1. Go through the whole process.
2. Find repeated information.
3. Check auto-population and selection.

**Expected result:** Auto-populate it or let the user select the previously entered information. All applicable states and normative exceptions have been checked.

**Fails when:** On the next step the user has to type an address they already provided again by hand.

## How to fix

Prefill the data or offer a "Use previous address" choice.

## Example

**Before:** The recipient enters their phone number again on the second step.

**After:** The number is prefilled and can be changed.

## Exceptions and false positives

Exceptions: re-entering the information is essential, is required for security, or the previously entered information is no longer valid. Do not merge independent processes automatically.

## Automation and evidence

A tool can collect candidates and measurements; the verdict depends on applicability, content, exceptions and observed behavior. The absence of an automated signal is not a pass. The main conclusion requires a person to carry out the scenario, or an observed interactive run; a static DOM alone is not enough.

- URL/route, interface state, date, sign-in method and the steps tested.
- Viewport in CSS px, zoom level, input method, user agent, and assistive technologies if used.
- The specific element/media segment/process step, reproducible observations and the actual result.
- The normative condition of 3.3.7, the exceptions checked, and an explanation of the barrier to the user.
- For this test, record: Go through the whole process; find repeated information; check auto-population and selection.
