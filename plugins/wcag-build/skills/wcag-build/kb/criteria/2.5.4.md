# 2.5.4 Motion Actuation

WCAG 2.2 · Level **A**

A practical summary in our own words; the exact obligations are set by the normative text and its definitions.

## Applicability

Functionality is triggered by device motion or user motion.

## What is required

Provide a user interface alternative and a way to disable responding to motion.

## How to test

1. Find shake, tilt and motion gestures.
2. Check the alternative buttons and the way to disable the response.

**Expected result:** Provide a user interface alternative and a way to disable responding to motion. All applicable states and normative exceptions have been checked.

**Fails when:** Input can be undone only by shaking, and the response to accidental shaking cannot be disabled.

## How to fix

Add a button and a setting that disables sensor-based control.

## Example

**Before:** A new route is built after shaking the device.

**After:** There is a "New route" button and a way to disable the gesture.

## Exceptions and false positives

Exceptions: the motion is used through an accessibility supported interface, or the motion is essential. Both requirements must be checked: the alternative and the ability to disable.

## Automation and evidence

A tool can collect candidates and measurements; the verdict depends on applicability, content, exceptions and observed behavior. The absence of an automated signal is not a pass. The main conclusion requires a person to carry out the scenario, or an observed interactive run; a static DOM alone is not enough.

- URL/route, interface state, date, sign-in method and the steps tested.
- Viewport in CSS px, zoom level, input method, user agent, and assistive technologies if used.
- The specific element/media segment/process step, reproducible observations and the actual result.
- The normative condition of 2.5.4, the exceptions checked, and an explanation of the barrier to the user.
- For this test, record: Find shake, tilt and motion gestures; check the alternative buttons and the way to disable the response.

## Code patterns

The scenario is given above. Code alone is not enough to test media, processes and semantics.
