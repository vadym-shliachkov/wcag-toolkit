# 2.2.2 Pause, Stop, Hide

WCAG 2.2 · Level **A**

A practical summary in our own words; the exact obligations are set by the normative text and its definitions.

## Applicability

Automatic moving, blinking or scrolling that lasts more than 5 seconds and is presented in parallel with other content; or automatic updating presented in parallel with other content.

## What is required

For moving content, provide pause/stop/hide; for updating content, also allow control of the update frequency, unless the activity is essential.

## How to test

1. Observe the page without interacting.
2. Measure how long the movement lasts.
3. Check the controls for updates and that the pause persists.

**Expected result:** For moving content, provide pause/stop/hide; for updating content, also allow control of the update frequency, unless the activity is essential. All applicable states and normative exceptions have been checked.

**Fails when:** A carousel moves endlessly with no accessible way to stop it.

## How to fix

Add an explicit control; keep the pause in effect until the user acts.

## Example

**Before:** A feed of tips updates continuously.

**After:** There is a "Pause updates" button.

## Exceptions and false positives

The 5-second threshold applies to moving, blinking and scrolling, but not to auto-updating information. Essential activity is an exception.

## Automation and evidence

A tool can collect candidates and measurements; the verdict depends on applicability, content, exceptions and observed behavior. The absence of an automated signal is not a pass. The main conclusion requires a person to carry out the scenario, or an observed interactive run; a static DOM alone is not enough.

- URL/route, interface state, date, sign-in method and the steps tested.
- Viewport in CSS px, zoom level, input method, user agent, and assistive technologies if used.
- The specific element/media segment/process step, reproducible observations and the actual result.
- The normative condition of 2.2.2, the exceptions checked, and an explanation of the barrier to the user.
- For this test, record: Observe the page without interacting; measure how long the movement lasts; check the controls for updates and that the pause persists.

## Code patterns

The scenario is given above. Code alone is not enough to test media, processes and semantics.
