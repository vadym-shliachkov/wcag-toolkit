# 2.4.4 Link Purpose (In Context)

WCAG 2.2 · Level **A**

A practical summary in our own words; the exact obligations are set by the normative text and its definitions.

## Applicability

All links.

## What is required

The purpose can be determined from the link text alone or together with its programmatically determined context.

## How to test

1. Read the link and its available context: sentence, paragraph, list item or associated table cell.
2. Compare it with the purpose.

**Expected result:** The purpose can be determined from the link text alone or together with its programmatically determined context. All applicable states and normative exceptions have been checked.

**Fails when:** "Open" leads to an unknown document, and there is no programmatic context.

## How to fix

Make the name more specific, or provide correctly associated context.

## Example

**Before:** A standalone "Next" link with no explanation.

**After:** "Open the book lending rules".

## Exceptions and false positives

If the purpose would be ambiguous to users in general, the exception applies. Do not require full understandability out of context: that is 2.4.9.

## Automation and evidence

A tool can collect candidates and measurements; the verdict depends on applicability, content, exceptions and observed behavior. The absence of an automated signal is not a pass. The main conclusion requires a person to carry out the scenario, or an observed interactive run; a static DOM alone is not enough.

- URL/route, interface state, date, sign-in method and the steps tested.
- Viewport in CSS px, zoom level, input method, user agent, and assistive technologies if used.
- The specific element/media segment/process step, reproducible observations and the actual result.
- The normative condition of 2.4.4, the exceptions checked, and an explanation of the barrier to the user.
- For this test, record: Read the link and its available context: sentence, paragraph, list item or associated table cell; compare it with the purpose.

## Code patterns

The scenario is given above. Code alone is not enough to test media, processes and semantics.
