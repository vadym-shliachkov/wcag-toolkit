# 3.3.8 Accessible Authentication (Minimum)

WCAG 2.2 · Level **AA**

A practical summary in our own words; the exact obligations are set by the normative text and its definitions.

## Applicability

Any step in an authentication process.

## What is required

Do not require a cognitive function test, except where an alternative method, a mechanism to assist, object recognition, or identification of the user's own non-text content is available.

## How to test

1. Go through every sign-in and recovery method.
2. Check paste, autofill and code transfer without having to memorize or transcribe anything.
3. Find alternatives to the tasks.

**Expected result:** Do not require a cognitive function test, except where an alternative method, a mechanism to assist, object recognition, or identification of the user's own non-text content is available. All applicable states and normative exceptions have been checked.

**Fails when:** Sign-in requires memorizing and manually transcribing a code, while paste and other assistance are blocked.

## How to fix

Allow paste and compatible mechanisms to assist, or provide a sign-in without a cognitive function test.

## Example

**Before:** A one-time code cannot be pasted; it has to be retyped.

**After:** The code can be pasted in full and is distributed correctly across the fields.

## Exceptions and false positives

A password is not prohibited if a mechanism to assist works. Object recognition and recognition of the user's own content are Level AA exceptions; check the applicability of each separately.

## Automation and evidence

A tool can collect candidates and measurements; the verdict depends on applicability, content, exceptions and observed behavior. The absence of an automated signal is not a pass. The main conclusion requires a person to carry out the scenario, or an observed interactive run; a static DOM alone is not enough.

- URL/route, interface state, date, sign-in method and the steps tested.
- Viewport in CSS px, zoom level, input method, user agent, and assistive technologies if used.
- The specific element/media segment/process step, reproducible observations and the actual result.
- The normative condition of 3.3.8, the exceptions checked, and an explanation of the barrier to the user.
- For this test, record: Go through every sign-in and recovery method; check paste, autofill and code transfer without having to memorize or transcribe anything; find alternatives to the tasks.
