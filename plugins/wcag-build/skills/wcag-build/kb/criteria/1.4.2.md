# 1.4.2 Audio Control

WCAG 2.2 · Level **A**

A practical summary in our own words; the exact obligations are set by the normative text and its definitions.

## Applicability

Audio plays automatically for more than 3 seconds.

## What is required

Provide a way to stop or pause the audio, or to control its volume independently of the overall system volume.

## How to test

1. Open the page without taking any action.
2. Measure the duration of the automatically playing audio.
3. Find and test the independent control.

**Expected result:** Provide a way to stop or pause the audio, or to control its volume independently of the overall system volume. All applicable states and normative exceptions have been checked.

**Fails when:** Background audio starts by itself and continues with no accessible way to turn it off.

## How to fix

Do not start audio automatically, or provide an accessible control mechanism.

## Example

**Before:** Background audio starts when the catalog opens.

**After:** The background audio starts only when the user presses a button.

## Exceptions and false positives

Audio that lasts 3 seconds or less is not covered by this criterion; playback started by a deliberate user action must be distinguished from autoplay.

## Automation and evidence

A tool can collect candidates and measurements; the verdict depends on applicability, content, exceptions and observed behavior. The absence of an automated signal is not a pass. The main conclusion requires a person to carry out the scenario, or an observed interactive run; a static DOM alone is not enough.

- URL/route, interface state, date, sign-in method and the steps tested.
- Viewport in CSS px, zoom level, input method, user agent, and assistive technologies if used.
- The specific element/media segment/process step, reproducible observations and the actual result.
- The normative condition of 1.4.2, the exceptions checked, and an explanation of the barrier to the user.
- For this test, record: Open the page without taking any action; measure the duration of the automatically playing audio; find and test the independent control.

## Code patterns

The scenario is given above. Code alone is not enough to test media, processes and semantics.
