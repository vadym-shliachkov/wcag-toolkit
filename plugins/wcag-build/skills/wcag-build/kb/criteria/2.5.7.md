# 2.5.7 Dragging Movements

WCAG 2.2 · Level **AA**

A practical summary in our own words; the exact obligations are set by the normative text and its definitions.

## Applicability

Functionality uses a dragging movement.

## What is required

Provide a way to achieve the function with a single pointer without dragging, unless dragging is essential or the behavior is determined by the user agent and not modified by the author.

## How to test

1. Find sorting, sliders and drag-to-move.
2. Achieve the same result with successive clicks/taps.

**Expected result:** Provide a way to achieve the function with a single pointer without dragging, unless dragging is essential or the behavior is determined by the user agent and not modified by the author. All applicable states and normative exceptions have been checked.

**Fails when:** A card can be moved to a column only by drag-and-drop.

## How to fix

Add a destination menu, move buttons or another single-pointer method.

## Example

**Before:** A task can be moved only by dragging.

**After:** A "Move to…" menu gives the same result.

## Exceptions and false positives

A keyboard alternative alone is not enough: this criterion needs a single-pointer alternative without dragging.

## Automation and evidence

A tool can collect candidates and measurements; the verdict depends on applicability, content, exceptions and observed behavior. The absence of an automated signal is not a pass. The main conclusion requires a person to carry out the scenario, or an observed interactive run; a static DOM alone is not enough.

- URL/route, interface state, date, sign-in method and the steps tested.
- Viewport in CSS px, zoom level, input method, user agent, and assistive technologies if used.
- The specific element/media segment/process step, reproducible observations and the actual result.
- The normative condition of 2.5.7, the exceptions checked, and an explanation of the barrier to the user.
- For this test, record: Find sorting, sliders and drag-to-move; achieve the same result with successive clicks/taps.
