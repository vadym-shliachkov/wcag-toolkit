# 1.2.7 Extended Audio Description (Prerecorded)

WCAG 2.2 · Level **AAA**

A practical summary in our own words; the exact obligations are set by the normative text and its definitions.

## Applicability

The video content needs description, and its natural pauses are not long enough for it; AAA.

## What is required

Provide extended audio description that pauses the video for the time of the additional narration.

## How to test

1. Compare the amount of meaningful visual events with the pauses.
2. Check the version with extended description.

**Expected result:** Provide extended audio description that pauses the video for the time of the additional narration. All applicable states and normative exceptions have been checked.

**Fails when:** A fast demonstration leaves no time to describe essential actions, and there is no extended version.

## How to fix

Create a version with additional pauses for description.

## Example

**Before:** Five operations with a device are shown quickly.

**After:** The extended version freezes the picture and explains each operation.

## Exceptions and false positives

If the pauses are long enough for standard description, extended description is not required by this criterion.

## Automation and evidence

A tool can collect candidates and measurements; the verdict depends on applicability, content, exceptions and observed behavior. The absence of an automated signal is not a pass. The main conclusion requires a person to carry out the scenario, or an observed interactive run; a static DOM alone is not enough.

- URL/route, interface state, date, sign-in method and the steps tested.
- Viewport in CSS px, zoom level, input method, user agent, and assistive technologies if used.
- The specific element/media segment/process step, reproducible observations and the actual result.
- The normative condition of 1.2.7, the exceptions checked, and an explanation of the barrier to the user.
- For this test, record: Compare the amount of meaningful visual events with the pauses; check the version with extended description.
