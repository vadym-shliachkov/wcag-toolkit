# 1.2.1 Audio-only and Video-only (Prerecorded)

WCAG 2.2 · Level **A**

A practical summary in our own words; the exact obligations are set by the normative text and its definitions.

## Applicability

Prerecorded audio-only or video-only material.

## What is required

For audio, provide an equivalent text alternative; for silent video, provide an equivalent text alternative or an audio track.

## How to test

1. Listen to or watch the whole material.
2. Find the alternative.
3. Check it against the events, speech and meaningful sounds.

**Expected result:** For audio, provide an equivalent text alternative; for silent video, provide an equivalent text alternative or an audio track. All applicable states and normative exceptions have been checked.

**Fails when:** A recorded audio interview is available only as sound.

## How to fix

Add a full transcript; for silent video, describe the actions and their sequence.

## Example

**Before:** The audio of a guided tour is available without any text.

**After:** A transcript is provided, including a description of the signal that starts the route.

## Exceptions and false positives

Does not apply to a media alternative for text that is already present, clearly labeled as such, if it adds no information.

## Automation and evidence

A tool can collect candidates and measurements; the verdict depends on applicability, content, exceptions and observed behavior. The absence of an automated signal is not a pass. The main conclusion requires a person to carry out the scenario, or an observed interactive run; a static DOM alone is not enough.

- URL/route, interface state, date, sign-in method and the steps tested.
- Viewport in CSS px, zoom level, input method, user agent, and assistive technologies if used.
- The specific element/media segment/process step, reproducible observations and the actual result.
- The normative condition of 1.2.1, the exceptions checked, and an explanation of the barrier to the user.
- For this test, record: Listen to or watch the whole material; find the alternative; check it against the events, speech and meaningful sounds.

## Code patterns

The scenario is given above. Code alone is not enough to test media, processes and semantics.
