# 2.5.8 Target Size (Minimum)

WCAG 2.2 · Level **AA**

A practical summary in our own words; the exact obligations are set by the normative text and its definitions.

## Applicability

Pointer input targets.

## What is required

The size is at least 24×24 CSS px, or one of the exceptions is met, including sufficient spacing.

## How to test

1. Measure the target areas.
2. For undersized targets, place a 24px-diameter circle centered on the bounding box of each one.
3. Check for intersections with other targets and with the circles of other small targets.

**Expected result:** The size is at least 24×24 CSS px, or one of the exceptions is met, including sufficient spacing. All applicable states and normative exceptions have been checked.

**Fails when:** Dense, small, separate buttons meet neither the size nor the spacing conditions.

## How to fix

Enlarge the targets or the spacing; where an alternative is relied on, check the equivalent target on the same page.

## Example

**Before:** Small day buttons sit tightly against each other.

**After:** Each has a 28×28 CSS px area.

## Exceptions and false positives

There are exceptions for inline targets, unmodified user agent controls, essential presentation, an equivalent target and spacing. Do not declare every element smaller than 24px a failure. Inline: the target is in a sentence, or its size is constrained by the line-height of the surrounding non-target text. Essential presentation also includes presentation that is legally required.

## Automation and evidence

A tool can collect candidates and measurements; the verdict depends on applicability, content, exceptions and observed behavior. The absence of an automated signal is not a pass. For this criterion it is especially important to compare the programmatic data with the actual presentation.

- URL/route, interface state, date, sign-in method and the steps tested.
- Viewport in CSS px, zoom level, input method, user agent, and assistive technologies if used.
- The specific element/media segment/process step, reproducible observations and the actual result.
- The normative condition of 2.5.8, the exceptions checked, and an explanation of the barrier to the user.
- For this test, record: Measure the target areas; for undersized targets, place a 24px-diameter circle centered on the bounding box of each one; check for intersections with other targets and with the circles of other small targets.
