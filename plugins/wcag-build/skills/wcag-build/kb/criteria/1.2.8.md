# 1.2.8 Media Alternative (Prerecorded)

WCAG 2.2 · Level **AAA**

A practical summary in our own words; the exact obligations are set by the normative text and its definitions.

## Applicability

All prerecorded synchronized media and prerecorded video without audio; AAA.

## What is required

Provide a full alternative that conveys auditory and visual information in the correct order.

## How to test

1. Check the alternative against the whole recording.
2. Check dialogue, actions and intended interactions.

**Expected result:** Provide a full alternative that conveys auditory and visual information in the correct order. All applicable states and normative exceptions have been checked.

**Fails when:** The transcript contains the speech but loses an important silent demonstration.

## How to fix

Prepare a coherent description of all essential events and interactions.

## Example

**Before:** The text for a video lists only the gardener's lines.

**After:** The text also describes the actions with the seedlings in the order they are shown.

## Exceptions and false positives

A plain list of spoken lines may not be a full media alternative; there is no general exception here for a "media alternative for text" as there is in several Level A criteria.

## Automation and evidence

A tool can collect candidates and measurements; the verdict depends on applicability, content, exceptions and observed behavior. The absence of an automated signal is not a pass. The main conclusion requires a person to carry out the scenario, or an observed interactive run; a static DOM alone is not enough.

- URL/route, interface state, date, sign-in method and the steps tested.
- Viewport in CSS px, zoom level, input method, user agent, and assistive technologies if used.
- The specific element/media segment/process step, reproducible observations and the actual result.
- The normative condition of 1.2.8, the exceptions checked, and an explanation of the barrier to the user.
- For this test, record: Check the alternative against the whole recording; check dialogue, actions and intended interactions.

## Code patterns

The scenario is given above. Code alone is not enough to test media, processes and semantics.
