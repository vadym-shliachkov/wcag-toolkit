# 3.3.9 Accessible Authentication (Enhanced)

WCAG 2.2 · Level **AAA**

A practical summary in our own words; the exact obligations are set by the normative text and its definitions.

## Applicability

Any authentication step; AAA.

## What is required

Do not require a cognitive function test without an alternative or a mechanism to assist.

## How to test

1. Check sign-in, the fallback path and recovery.
2. Separately examine object recognition and recognition of the user's own content.

**Expected result:** Do not require a cognitive function test without an alternative or a mechanism to assist. All applicable states and normative exceptions have been checked.

**Fails when:** Sign-in depends on image recognition with no alternative or assistance.

## How to fix

Provide an accessible authentication method without such a task.

## Example

**Before:** Sign-in is possible only after selecting objects in an image.

**After:** An equivalent path without recognition is provided.

## Exceptions and false positives

The 3.3.8 exceptions for objects and the user's own content do not apply here; the alternative method and the mechanism to assist remain.

## Automation and evidence

A tool can collect candidates and measurements; the verdict depends on applicability, content, exceptions and observed behavior. The absence of an automated signal is not a pass. The main conclusion requires a person to carry out the scenario, or an observed interactive run; a static DOM alone is not enough.

- URL/route, interface state, date, sign-in method and the steps tested.
- Viewport in CSS px, zoom level, input method, user agent, and assistive technologies if used.
- The specific element/media segment/process step, reproducible observations and the actual result.
- The normative condition of 3.3.9, the exceptions checked, and an explanation of the barrier to the user.
- For this test, record: Check sign-in, the fallback path and recovery; separately examine object recognition and recognition of the user's own content.

## Code patterns

The scenario is given above. Code alone is not enough to test media, processes and semantics.
