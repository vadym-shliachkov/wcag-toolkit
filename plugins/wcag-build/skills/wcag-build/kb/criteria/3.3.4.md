# 3.3.4 Error Prevention (Legal, Financial, Data)

WCAG 2.2 · Level **AA**

A practical summary in our own words; the exact obligations are set by the normative text and its definitions.

## Applicability

Legal commitments, financial transactions, modifying or deleting user-controllable data in data storage systems, or submitting test responses.

## What is required

Provide reversibility, checking with an opportunity to correct, or review/confirmation/correction before finalizing.

## How to test

1. Determine the type of action.
2. Check at least one complete protection mechanism.
3. Try to correct what was found.

**Expected result:** Provide reversibility, checking with an opportunity to correct, or review/confirmation/correction before finalizing. All applicable states and normative exceptions have been checked.

**Fails when:** Irreversible deletion of a saved collection completes without checking or confirmation.

## How to fix

Provide recovery, or a review/confirmation step with correction.

## Example

**Before:** A saved set of observations is deleted immediately.

**After:** The deleted set can be restored.

## Exceptions and false positives

Not every ordinary search falls under this criterion; the applicability conditions are mandatory. One of the three specified mechanisms is enough.

## Automation and evidence

A tool can collect candidates and measurements; the verdict depends on applicability, content, exceptions and observed behavior. The absence of an automated signal is not a pass. The main conclusion requires a person to carry out the scenario, or an observed interactive run; a static DOM alone is not enough.

- URL/route, interface state, date, sign-in method and the steps tested.
- Viewport in CSS px, zoom level, input method, user agent, and assistive technologies if used.
- The specific element/media segment/process step, reproducible observations and the actual result.
- The normative condition of 3.3.4, the exceptions checked, and an explanation of the barrier to the user.
- For this test, record: Determine the type of action; check at least one complete protection mechanism; try to correct what was found.

## Code patterns

The scenario is given above. Code alone is not enough to test media, processes and semantics.
