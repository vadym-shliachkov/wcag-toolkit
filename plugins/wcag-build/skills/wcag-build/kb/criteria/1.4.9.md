# 1.4.9 Images of Text (No Exception)

WCAG 2.2 · Level **AAA**

A practical summary in our own words; the exact obligations are set by the normative text and its definitions.

## Applicability

Images of text; AAA.

## What is required

Use images of text only for pure decoration or where the particular presentation is essential.

## How to test

1. Find images that contain text.
2. Determine their purpose and whether the presentation is essential.

**Expected result:** Use images of text only for pure decoration or where the particular presentation is essential. All applicable states and normative exceptions have been checked.

**Fails when:** Even a customizable image replaces ordinary meaningful text without an essential reason.

## How to fix

Present meaningful text as text.

## Example

**Before:** An image contains the booking rules.

**After:** The rules are available as HTML text.

## Exceptions and false positives

Logotypes are essential presentation. Unlike 1.4.5, an image being customizable is not an exception on its own.

## Automation and evidence

A tool can collect candidates and measurements; the verdict depends on applicability, content, exceptions and observed behavior. The absence of an automated signal is not a pass. The main conclusion requires a person to carry out the scenario, or an observed interactive run; a static DOM alone is not enough.

- URL/route, interface state, date, sign-in method and the steps tested.
- Viewport in CSS px, zoom level, input method, user agent, and assistive technologies if used.
- The specific element/media segment/process step, reproducible observations and the actual result.
- The normative condition of 1.4.9, the exceptions checked, and an explanation of the barrier to the user.
- For this test, record: Find images that contain text; determine their purpose and whether the presentation is essential.

## Code patterns

The scenario is given above. Code alone is not enough to test media, processes and semantics.
