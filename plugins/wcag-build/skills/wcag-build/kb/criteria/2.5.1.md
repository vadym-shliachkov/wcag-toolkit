# 2.5.1 Pointer Gestures

WCAG 2.2 · Level **A**

A practical summary in our own words; the exact obligations are set by the normative text and its definitions.

## Applicability

Functionality uses a multipoint or path-based gesture.

## What is required

Provide operation with a single pointer without a path-based gesture, unless the gesture is essential.

## How to test

1. Perform the function with a single tap or click.
2. Check the alternative to pinching and to a specified path.

**Expected result:** Provide operation with a single pointer without a path-based gesture, unless the gesture is essential. All applicable states and normative exceptions have been checked.

**Fails when:** A map can be zoomed only by pinching, with no zoom buttons.

## How to fix

Add buttons or another simple single-point input.

## Example

**Before:** The diagram's zoom can be changed only with two fingers.

**After:** There are "Zoom in" and "Zoom out" buttons.

## Exceptions and false positives

Ordinary dragging is not always a path-based gesture; check 2.5.7 separately. The essential exception must relate to the function, not the implementation.

## Automation and evidence

A tool can collect candidates and measurements; the verdict depends on applicability, content, exceptions and observed behavior. The absence of an automated signal is not a pass. The main conclusion requires a person to carry out the scenario, or an observed interactive run; a static DOM alone is not enough.

- URL/route, interface state, date, sign-in method and the steps tested.
- Viewport in CSS px, zoom level, input method, user agent, and assistive technologies if used.
- The specific element/media segment/process step, reproducible observations and the actual result.
- The normative condition of 2.5.1, the exceptions checked, and an explanation of the barrier to the user.
- For this test, record: Perform the function with a single tap or click; check the alternative to pinching and to a specified path.

## Code patterns

The scenario is given above. Code alone is not enough to test media, processes and semantics.
