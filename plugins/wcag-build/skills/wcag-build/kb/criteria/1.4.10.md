# 1.4.10 Reflow

WCAG 2.2 · Level **AA**

A practical summary in our own words; the exact obligations are set by the normative text and its definitions.

## Applicability

Content that scrolls vertically or horizontally.

## What is required

At a width of 320 CSS px for vertically scrolling content, or a height of 256 CSS px for horizontally scrolling content, no information or functionality is lost and scrolling in two dimensions is not required.

## How to test

1. Set the required CSS viewport, or the equivalent 400% zoom in a 1280×1024 window.
2. Go through the states.
3. Identify the permitted two-dimensional areas.

**Expected result:** At a width of 320 CSS px for vertically scrolling content, or a height of 256 CSS px for horizontally scrolling content, no information or functionality is lost and scrolling in two dimensions is not required. All applicable states and normative exceptions have been checked.

**Fails when:** Reading an ordinary paragraph on a narrow screen requires moving both horizontally and vertically.

## How to fix

Allow wrapping and a responsive layout; confine any necessary two-dimensional scrolling to its own area.

## Example

**Before:** The form text has min-width 900px.

**After:** Fields and labels stack into a single column at 320px.

## Exceptions and false positives

Data tables, maps and other areas where two-dimensional layout is essential to meaning or use may be excluded; the exception does not extend to the whole page.

## Automation and evidence

A tool can collect candidates and measurements; the verdict depends on applicability, content, exceptions and observed behavior. The absence of an automated signal is not a pass. The main conclusion requires a person to carry out the scenario, or an observed interactive run; a static DOM alone is not enough.

- URL/route, interface state, date, sign-in method and the steps tested.
- Viewport in CSS px, zoom level, input method, user agent, and assistive technologies if used.
- The specific element/media segment/process step, reproducible observations and the actual result.
- The normative condition of 1.4.10, the exceptions checked, and an explanation of the barrier to the user.
- For this test, record: Set the required CSS viewport, or the equivalent 400% zoom in a 1280×1024 window; go through the states; identify the permitted two-dimensional areas.
