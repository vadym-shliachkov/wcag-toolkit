# 1.4.12 Text Spacing

WCAG 2.2 · Level **AA**

A practical summary in our own words; the exact obligations are set by the normative text and its definitions.

## Applicability

Content in markup that supports the listed properties.

## What is required

When line-height is overridden to 1.5, spacing after paragraphs to 2 times the font size, letter-spacing to 0.12em and word-spacing to 0.16em, no content or functionality is lost.

## How to test

1. Apply all four values at once, taking the language into account, without changing any other properties.
2. Check for clipping, overlaps, menus and messages.

**Expected result:** When line-height is overridden to 1.5, spacing after paragraphs to 2 times the font size, letter-spacing to 0.12em and word-spacing to 0.16em, no content or functionality is lost. All applicable states and normative exceptions have been checked.

**Fails when:** After the spacing is increased, a label overlaps the adjacent field and becomes unusable.

## How to fix

Allow containers to grow and text to wrap; remove constraints that clip text.

## Example

**Before:** An error message is hidden by a fixed height.

**After:** The error block expands with user-defined spacing.

## Exceptions and false positives

These values do not have to be applied by default. Properties that the given language or script does not use are not required in that case.

## Automation and evidence

A tool can collect candidates and measurements; the verdict depends on applicability, content, exceptions and observed behavior. The absence of an automated signal is not a pass. The main conclusion requires a person to carry out the scenario, or an observed interactive run; a static DOM alone is not enough.

- URL/route, interface state, date, sign-in method and the steps tested.
- Viewport in CSS px, zoom level, input method, user agent, and assistive technologies if used.
- The specific element/media segment/process step, reproducible observations and the actual result.
- The normative condition of 1.4.12, the exceptions checked, and an explanation of the barrier to the user.
- For this test, record: Apply all four values at once, taking the language into account, without changing any other properties; check for clipping, overlaps, menus and messages.
