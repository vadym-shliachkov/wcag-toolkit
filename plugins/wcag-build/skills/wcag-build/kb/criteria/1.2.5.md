# 1.2.5 Audio Description (Prerecorded)

WCAG 2.2 · Level **AA**

A practical summary in our own words; the exact obligations are set by the normative text and its definitions.

## Applicability

Prerecorded video in synchronized media contains meaningful visual information.

## What is required

Convey meaningful visual events through audio description.

## How to test

1. Listen without the picture.
2. Identify actions, on-screen text and scene changes that are not conveyed.
3. Check the audio description.

**Expected result:** Convey meaningful visual events through audio description. All applicable states and normative exceptions have been checked.

**Fails when:** The meaning of a silent demonstration is missing from the audio track.

## How to fix

Add audio description or a version with integrated description of the visual actions.

## Example

**Before:** In a video, the order of parts is silently changed.

**After:** A voice describes the new order in a pause between lines of dialogue.

## Exceptions and false positives

No additional track is needed when the main audio already conveys all important visual information. A transcript does not meet the Level AA requirement.

## Automation and evidence

A tool can collect candidates and measurements; the verdict depends on applicability, content, exceptions and observed behavior. The absence of an automated signal is not a pass. The main conclusion requires a person to carry out the scenario, or an observed interactive run; a static DOM alone is not enough.

- URL/route, interface state, date, sign-in method and the steps tested.
- Viewport in CSS px, zoom level, input method, user agent, and assistive technologies if used.
- The specific element/media segment/process step, reproducible observations and the actual result.
- The normative condition of 1.2.5, the exceptions checked, and an explanation of the barrier to the user.
- For this test, record: Listen without the picture; identify actions, on-screen text and scene changes that are not conveyed; check the audio description.

## Code patterns

The scenario is given above. Code alone is not enough to test media, processes and semantics.
