# 1.3.5 Identify Input Purpose

WCAG 2.2 · Level **AA**

A practical summary in our own words; the exact obligations are set by the normative text and its definitions.

## Applicability

Fields collect information about the user and serve one of the purposes listed in the standard.

## What is required

Programmatically identify the purpose where the technology supports it.

## How to test

1. Determine that the field concerns the user's own data.
2. Match the purpose against the Input Purposes list.
3. Check that autocomplete is correct.

**Expected result:** Programmatically identify the purpose where the technology supports it. All applicable states and normative exceptions have been checked.

**Fails when:** A field for the user's own postal code does not expose a supported purpose.

## How to fix

Set a correct autocomplete token and keep a visible label.

## Example

**Before:** A personal phone field has only type="tel".

**After:** The field gets autocomplete="tel" and a label.

## Exceptions and false positives

Do not require tokens for every search, arbitrary identifier or information about another person; type alone does not always convey the required purpose.

## Automation and evidence

A tool can collect candidates and measurements; the verdict depends on applicability, content, exceptions and observed behavior. The absence of an automated signal is not a pass. For this criterion it is especially important to compare the programmatic data with the actual presentation.

- URL/route, interface state, date, sign-in method and the steps tested.
- Viewport in CSS px, zoom level, input method, user agent, and assistive technologies if used.
- The specific element/media segment/process step, reproducible observations and the actual result.
- The normative condition of 1.3.5, the exceptions checked, and an explanation of the barrier to the user.
- For this test, record: Determine that the field concerns the user's own data; match the purpose against the Input Purposes list; check that autocomplete is correct.
