# Section heading

Criteria: [1.3.1](../criteria/1.3.1.md), [2.4.6](../criteria/2.4.6.md).

A teaching snippet we wrote ourselves. Apply it with regard to context; it does not certify conformance of the whole component.

## Problematic version

```html
<div class="large-text">Renewing a loan</div>
```

## Fixed version or implementation contract

```html
<h2>Renewing a loan</h2>
<p>You can extend the loan period before the return date.</p>
```

## What to check

Check that this really is a heading and that its level reflects how the section is nested. A single h1 is a practical convention, not a separate universal criterion.
