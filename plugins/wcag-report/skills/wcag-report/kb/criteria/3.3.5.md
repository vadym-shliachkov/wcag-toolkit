# 3.3.5 Help

WCAG 2.2 · Level **AAA**

A practical summary in our own words; the exact obligations are set by the normative text and its definitions.

## Applicability

Input and other functions for which a label alone is not enough to explain the action; AAA.

## What is required

Provide help relevant to the current context.

## How to test

1. Check complex fields and actions where the label does not explain the whole function.
2. Find help available nearby or through a clear mechanism.

**Expected result:** Provide help relevant to the current context. All applicable states and normative exceptions have been checked.

**Fails when:** The user cannot get an explanation of a complex data format in the current form.

## How to fix

Add help that explains the purpose and how to fill it in.

## Example

**Before:** A coordinates field does not explain the notation.

**After:** An explanation of the format and of how to determine the values is available.

## Exceptions and false positives

A general contact in the footer is not always context-sensitive help; assess its usefulness for the current input. According to the Understanding document, separate help is needed where the label does not explain the whole function; the availability of help must be obvious.

## Automation and evidence

A tool can collect candidates and measurements; the verdict depends on applicability, content, exceptions and observed behavior. The absence of an automated signal is not a pass. The main conclusion requires a person to carry out the scenario, or an observed interactive run; a static DOM alone is not enough.

- URL/route, interface state, date, sign-in method and the steps tested.
- Viewport in CSS px, zoom level, input method, user agent, and assistive technologies if used.
- The specific element/media segment/process step, reproducible observations and the actual result.
- The normative condition of 3.3.5, the exceptions checked, and an explanation of the barrier to the user.
- For this test, record: Check complex fields and actions where the label does not explain the whole function; find help available nearby or through a clear mechanism.

## Code patterns

The scenario is given above. Code alone is not enough to test media, processes and semantics.
