# 3.2.1 On Focus

WCAG 2.2 · Level **A**

A practical summary in our own words; the exact obligations are set by the normative text and its definitions.

## Applicability

Any component receives focus.

## What is required

Receiving focus does not by itself cause a change of context.

## How to test

1. Move through the page with Tab without activating anything.
2. Check for route changes, new windows, focus movement and significant changes to the presentation.

**Expected result:** Receiving focus does not by itself cause a change of context. All applicable states and normative exceptions have been checked.

**Fails when:** When a link receives focus, another page opens automatically.

## How to fix

Move the navigation to explicit activation.

## Example

**Before:** Focusing an option starts navigation to the application.

**After:** Navigation happens only after activation.

## Exceptions and false positives

A tooltip appearing or a small update is not necessarily a change of context; assess it against the definition of change of context.

## Automation and evidence

A tool can collect candidates and measurements; the verdict depends on applicability, content, exceptions and observed behavior. The absence of an automated signal is not a pass. The main conclusion requires a person to carry out the scenario, or an observed interactive run; a static DOM alone is not enough.

- URL/route, interface state, date, sign-in method and the steps tested.
- Viewport in CSS px, zoom level, input method, user agent, and assistive technologies if used.
- The specific element/media segment/process step, reproducible observations and the actual result.
- The normative condition of 3.2.1, the exceptions checked, and an explanation of the barrier to the user.
- For this test, record: Move through the page with Tab without activating anything; check for route changes, new windows, focus movement and significant changes to the presentation.

## Code patterns

The scenario is given above. Code alone is not enough to test media, processes and semantics.
