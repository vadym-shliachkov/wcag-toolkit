# 1.2.9 Audio-only (Live)

WCAG 2.2 · Level **AAA**

A practical summary in our own words; the exact obligations are set by the normative text and its definitions.

## Applicability

A live audio-only broadcast without video; AAA.

## What is required

Provide a text alternative that conveys information equivalent to the live audio.

## How to test

1. Join the live broadcast.
2. Find a parallel text alternative.
3. Compare the content.

**Expected result:** Provide a text alternative that conveys information equivalent to the live audio. All applicable states and normative exceptions have been checked.

**Fails when:** Audio announcements are available on air without equivalent text.

## How to fix

Provide a text stream or another way to get equivalent information, as the conditions of the event allow.

## Example

**Before:** An audio channel announces that a class has been rescheduled.

**After:** The message is available at the same time in a text feed.

## Exceptions and false positives

Do not mix this up with captions for synchronized live media under 1.2.4; the content and format of the alternative are assessed in context.

## Automation and evidence

A tool can collect candidates and measurements; the verdict depends on applicability, content, exceptions and observed behavior. The absence of an automated signal is not a pass. The main conclusion requires a person to carry out the scenario, or an observed interactive run; a static DOM alone is not enough.

- URL/route, interface state, date, sign-in method and the steps tested.
- Viewport in CSS px, zoom level, input method, user agent, and assistive technologies if used.
- The specific element/media segment/process step, reproducible observations and the actual result.
- The normative condition of 1.2.9, the exceptions checked, and an explanation of the barrier to the user.
- For this test, record: Join the live broadcast; find a parallel text alternative; compare the content.

## Code patterns

The scenario is given above. Code alone is not enough to test media, processes and semantics.
