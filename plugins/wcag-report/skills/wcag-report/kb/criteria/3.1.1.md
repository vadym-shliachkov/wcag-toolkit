# 3.1.1 Language of Page

WCAG 2.2 · Level **A**

A practical summary in our own words; the exact obligations are set by the normative text and its definitions.

## Applicability

Any web page.

## What is required

The default human language can be programmatically determined.

## How to test

1. Check the lang attribute on the root html element, whether the language tag is valid, and the actual default language.

**Expected result:** The default human language can be programmatically determined. All applicable states and normative exceptions have been checked.

**Fails when:** A Russian-language page has no determinable language.

## How to fix

Set a correct lang on html.

## Example

**Before:** A document in Russian has html without lang.

**After:** html lang="ru".

## Exceptions and false positives

Do not infer the language from the domain, the browser interface or a single word alone. A language mismatch requires checking the actual content.

## Automation and evidence

A tool can collect candidates and measurements; the verdict depends on applicability, content, exceptions and observed behavior. The absence of an automated signal is not a pass. For this criterion it is especially important to compare the programmatic data with the actual presentation.

- URL/route, interface state, date, sign-in method and the steps tested.
- Viewport in CSS px, zoom level, input method, user agent, and assistive technologies if used.
- The specific element/media segment/process step, reproducible observations and the actual result.
- The normative condition of 3.1.1, the exceptions checked, and an explanation of the barrier to the user.
- For this test, record: Check the lang attribute on the root html element, whether the language tag is valid, and the actual default language.
