# 1.3.1 Info and Relationships

WCAG 2.2 · Level **A**

A practical summary in our own words; the exact obligations are set by the normative text and its definitions.

## Applicability

Headings, lists, tables, field groups, labels and other visually expressed relationships.

## What is required

Relationships and structure can be programmatically determined or are available in text.

## How to test

1. Compare the visual structure with the DOM and the accessibility tree.
2. Check label, headers and scope associations and the grouping of fields.

**Expected result:** Relationships and structure can be programmatically determined or are available in text. All applicable states and normative exceptions have been checked.

**Fails when:** Column names are shown in bold but are not associated with the data cells.

## How to fix

Use semantic elements and explicit programmatic associations.

## Example

**Before:** Delivery options are grouped only by a border.

**After:** The fieldset and legend elements convey the name of the group.

## Exceptions and false positives

Not every skipped heading level or missing landmark is automatically a failure. A loss of expressed information or relationships must be shown.

## Automation and evidence

A tool can collect candidates and measurements; the verdict depends on applicability, content, exceptions and observed behavior. The absence of an automated signal is not a pass. For this criterion it is especially important to compare the programmatic data with the actual presentation.

- URL/route, interface state, date, sign-in method and the steps tested.
- Viewport in CSS px, zoom level, input method, user agent, and assistive technologies if used.
- The specific element/media segment/process step, reproducible observations and the actual result.
- The normative condition of 1.3.1, the exceptions checked, and an explanation of the barrier to the user.
- For this test, record: Compare the visual structure with the DOM and the accessibility tree; check label, headers and scope associations and the grouping of fields.
