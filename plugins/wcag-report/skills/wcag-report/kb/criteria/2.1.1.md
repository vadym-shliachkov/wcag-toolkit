# 2.1.1 Keyboard

WCAG 2.2 · Level **A**

A practical summary in our own words; the exact obligations are set by the normative text and its definitions.

## Applicability

All functionality, except input that essentially depends on the path of the user's movement.

## What is required

Make functionality operable through a keyboard interface without requiring specific timings for keystrokes.

## How to test

1. Move through the page with Tab and Shift+Tab.
2. Perform the operations with Enter, Space and the relevant keys.
3. Check alternatives to dragging and gestures.

**Expected result:** Make functionality operable through a keyboard interface without requiring specific timings for keystrokes. All applicable states and normative exceptions have been checked.

**Fails when:** A section disclosure button works only on a mouse click.

## How to fix

Use a native button, or implement full keyboard operation with correct semantics.

## Example

**Before:** The sort panel opens only with a mouse.

**After:** A button opens it with Enter and Space.

## Exceptions and false positives

Freehand drawing can essentially depend on the path; ordinary moving of an item by coordinates does not automatically qualify for this exception.

## Automation and evidence

A tool can collect candidates and measurements; the verdict depends on applicability, content, exceptions and observed behavior. The absence of an automated signal is not a pass. The main conclusion requires a person to carry out the scenario, or an observed interactive run; a static DOM alone is not enough.

- URL/route, interface state, date, sign-in method and the steps tested.
- Viewport in CSS px, zoom level, input method, user agent, and assistive technologies if used.
- The specific element/media segment/process step, reproducible observations and the actual result.
- The normative condition of 2.1.1, the exceptions checked, and an explanation of the barrier to the user.
- For this test, record: Move through the page with Tab and Shift+Tab; perform the operations with Enter, Space and the relevant keys; check alternatives to dragging and gestures.
