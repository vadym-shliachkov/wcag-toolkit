# 1.2.3 Audio Description or Media Alternative (Prerecorded)

WCAG 2.2 · Level **A**

A practical summary in our own words; the exact obligations are set by the normative text and its definitions.

## Applicability

Prerecorded synchronized media contains meaningful visual events.

## What is required

At Level A, either audio description or a full alternative for time-based media is sufficient.

## How to test

1. Play the video without looking at the picture.
2. Find visual information that cannot be heard.
3. Check it against the description or the full text alternative.

**Expected result:** At Level A, either audio description or a full alternative for time-based media is sufficient. All applicable states and normative exceptions have been checked.

**Fails when:** An assembly step is demonstrated that cannot be understood from the audio and is missing from the alternative.

## How to fix

Describe the visual events and their sequence; where there is interactivity, include a way to achieve the result.

## Example

**Before:** The presenter silently turns a valve.

**After:** The full alternative describes the direction and the moment of the turn.

## Exceptions and false positives

Do not confuse this with 1.2.5: at Level AA, a text alternative alone is usually not enough. The exception for a media alternative for text that is labeled as such applies.

## Automation and evidence

A tool can collect candidates and measurements; the verdict depends on applicability, content, exceptions and observed behavior. The absence of an automated signal is not a pass. The main conclusion requires a person to carry out the scenario, or an observed interactive run; a static DOM alone is not enough.

- URL/route, interface state, date, sign-in method and the steps tested.
- Viewport in CSS px, zoom level, input method, user agent, and assistive technologies if used.
- The specific element/media segment/process step, reproducible observations and the actual result.
- The normative condition of 1.2.3, the exceptions checked, and an explanation of the barrier to the user.
- For this test, record: Play the video without looking at the picture; find visual information that cannot be heard; check it against the description or the full text alternative.

## Code patterns

The scenario is given above. Code alone is not enough to test media, processes and semantics.
