# 2.5.6 Concurrent Input Mechanisms

WCAG 2.2 · Level **AAA**

A practical summary in our own words; the exact obligations are set by the normative text and its definitions.

## Applicability

The platform supports different input modalities; AAA.

## What is required

Do not restrict the available input modalities, unless the restriction is essential, required for security, or required to respect user settings.

## How to test

1. On one device, alternate between keyboard, touch and pointer.
2. Check access to the functionality.

**Expected result:** Do not restrict the available input modalities, unless the restriction is essential, required for security, or required to respect user settings. All applicable states and normative exceptions have been checked.

**Fails when:** After the first touch, the interface disables the keyboard for no reason.

## How to fix

Keep supporting input modalities concurrently.

## Example

**Before:** A touch switches the form into a mode where Tab stops working.

**After:** Input switches freely between devices.

## Exceptions and false positives

A different layout is not the same as restricting input; the permitted exceptions require a specific justification.

## Automation and evidence

A tool can collect candidates and measurements; the verdict depends on applicability, content, exceptions and observed behavior. The absence of an automated signal is not a pass. The main conclusion requires a person to carry out the scenario, or an observed interactive run; a static DOM alone is not enough.

- URL/route, interface state, date, sign-in method and the steps tested.
- Viewport in CSS px, zoom level, input method, user agent, and assistive technologies if used.
- The specific element/media segment/process step, reproducible observations and the actual result.
- The normative condition of 2.5.6, the exceptions checked, and an explanation of the barrier to the user.
- For this test, record: On one device, alternate between keyboard, touch and pointer; check access to the functionality.

## Code patterns

The scenario is given above. Code alone is not enough to test media, processes and semantics.
