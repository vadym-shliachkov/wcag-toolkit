# 1.4.8 Visual Presentation

WCAG 2.2 · Level **AAA**

A practical summary in our own words; the exact obligations are set by the normative text and its definitions.

## Applicability

Blocks of text; AAA.

## What is required

Provide a mechanism for selecting colors; limit lines to 80 characters, 40 for CJK; avoid justification to both edges; provide line spacing of 1.5 and paragraph spacing of 1.5 times the line spacing; at 200% zoom, no horizontal scrolling is needed to read a line in a full-screen window.

## How to test

1. Check the available customization mechanisms and every listed parameter.
2. Check 200% zoom separately.

**Expected result:** Provide a mechanism for selecting colors; limit lines to 80 characters, 40 for CJK; avoid justification to both edges; provide line spacing of 1.5 and paragraph spacing of 1.5 times the line spacing; at 200% zoom, no horizontal scrolling is needed to read a line in a full-screen window. All applicable states and normative exceptions have been checked.

**Fails when:** Long lines and dense paragraphs cannot be changed with an available mechanism.

## How to fix

Provide reading settings or a compatible presentation with the required parameters.

## Example

**Before:** A journal displays long lines with justified alignment.

**After:** A reading mode limits line length and lets the user choose colors.

## Exceptions and false positives

The criterion requires a mechanism; the parameters do not all have to be defaults. Do not mix this up with the spacing override test of 1.4.12. The mechanism may be provided by the user agent; a page's own settings panel is not required.

## Automation and evidence

A tool can collect candidates and measurements; the verdict depends on applicability, content, exceptions and observed behavior. The absence of an automated signal is not a pass. The main conclusion requires a person to carry out the scenario, or an observed interactive run; a static DOM alone is not enough.

- URL/route, interface state, date, sign-in method and the steps tested.
- Viewport in CSS px, zoom level, input method, user agent, and assistive technologies if used.
- The specific element/media segment/process step, reproducible observations and the actual result.
- The normative condition of 1.4.8, the exceptions checked, and an explanation of the barrier to the user.
- For this test, record: Check the available customization mechanisms and every listed parameter; check 200% zoom separately.

## Code patterns

The scenario is given above. Code alone is not enough to test media, processes and semantics.
