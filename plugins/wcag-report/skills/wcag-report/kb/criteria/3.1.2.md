# 3.1.2 Language of Parts

WCAG 2.2 · Level **AA**

A practical summary in our own words; the exact obligations are set by the normative text and its definitions.

## Applicability

Passages in a different human language.

## What is required

Programmatically identify the language of each such passage, except for the normative exceptions.

## How to test

1. Find phrases in other languages.
2. Check the nearest lang and how assistive technology pronounces the phrase.

**Expected result:** Programmatically identify the language of each such passage, except for the normative exceptions. All applicable states and normative exceptions have been checked.

**Fails when:** A long English quotation inherits the Russian language and has no language markup of its own.

## How to fix

Mark up the passage with the correct lang.

## Example

**Before:** "Please return the key" sits in a Russian paragraph without lang.

**After:** The phrase is wrapped in span lang="en".

## Exceptions and false positives

Proper names, technical terms, words of indeterminate language, and borrowed words that have become part of the surrounding language can be exceptions.

## Automation and evidence

A tool can collect candidates and measurements; the verdict depends on applicability, content, exceptions and observed behavior. The absence of an automated signal is not a pass. For this criterion it is especially important to compare the programmatic data with the actual presentation.

- URL/route, interface state, date, sign-in method and the steps tested.
- Viewport in CSS px, zoom level, input method, user agent, and assistive technologies if used.
- The specific element/media segment/process step, reproducible observations and the actual result.
- The normative condition of 3.1.2, the exceptions checked, and an explanation of the barrier to the user.
- For this test, record: Find phrases in other languages; check the nearest lang and how assistive technology pronounces the phrase.
