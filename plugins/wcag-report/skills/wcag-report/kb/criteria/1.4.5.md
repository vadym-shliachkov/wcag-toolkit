# 1.4.5 Images of Text

WCAG 2.2 · Level **AA**

A practical summary in our own words; the exact obligations are set by the normative text and its definitions.

## Applicability

The technology can produce the required visual presentation with ordinary text.

## What is required

Use text instead of an image of it, except for presentation that is customizable or essential.

## How to test

1. Find text in raster and vector images.
2. Check whether the presentation is essential and whether it can be customized.

**Expected result:** Use text instead of an image of it, except for presentation that is customizable or essential. All applicable states and normative exceptions have been checked.

**Fails when:** An announcement heading is baked into an image for the sake of a chosen font.

## How to fix

Replace the image with live text styled with CSS.

## Example

**Before:** Opening hours are written only on a banner.

**After:** The hours are shown as ordinary text over a decorative background.

## Exceptions and false positives

A logotype is considered essential; the mere fact that an image contains text does not yet rule out the exceptions. Text in a photograph of a real object is assessed in context.

## Automation and evidence

A tool can collect candidates and measurements; the verdict depends on applicability, content, exceptions and observed behavior. The absence of an automated signal is not a pass. The main conclusion requires a person to carry out the scenario, or an observed interactive run; a static DOM alone is not enough.

- URL/route, interface state, date, sign-in method and the steps tested.
- Viewport in CSS px, zoom level, input method, user agent, and assistive technologies if used.
- The specific element/media segment/process step, reproducible observations and the actual result.
- The normative condition of 1.4.5, the exceptions checked, and an explanation of the barrier to the user.
- For this test, record: Find text in raster and vector images; check whether the presentation is essential and whether it can be customized.

## Code patterns

The scenario is given above. Code alone is not enough to test media, processes and semantics.
