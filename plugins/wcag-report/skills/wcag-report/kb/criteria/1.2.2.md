# 1.2.2 Captions (Prerecorded)

WCAG 2.2 · Level **A**

A practical summary in our own words; the exact obligations are set by the normative text and its definitions.

## Applicability

A prerecorded synchronized media program with audio.

## What is required

Captions convey speech and meaningful sounds with proper synchronization and speaker identification.

## How to test

1. Turn on the captions.
2. Compare them with the full audio track.
3. Check speaker changes and meaningful sounds.

**Expected result:** Captions convey speech and meaningful sounds with proper synchronization and speaker identification. All applicable states and normative exceptions have been checked.

**Fails when:** With the sound off, a warning that is not in the captions is lost.

## How to fix

Add proofread captions and an accessible control for turning them on.

## Example

**Before:** In a greenhouse video, a heat warning is heard but not captioned.

**After:** The warning and the siren sound are present in the captions.

## Exceptions and false positives

The exception is a media alternative for text that is clearly labeled as such. The presence of a track file does not confirm caption quality. Permanently visible open captions are acceptable; a toggle is needed for the chosen implementation of closed captions, not as a separate universal requirement.

## Automation and evidence

A tool can collect candidates and measurements; the verdict depends on applicability, content, exceptions and observed behavior. The absence of an automated signal is not a pass. The main conclusion requires a person to carry out the scenario, or an observed interactive run; a static DOM alone is not enough.

- URL/route, interface state, date, sign-in method and the steps tested.
- Viewport in CSS px, zoom level, input method, user agent, and assistive technologies if used.
- The specific element/media segment/process step, reproducible observations and the actual result.
- The normative condition of 1.2.2, the exceptions checked, and an explanation of the barrier to the user.
- For this test, record: Turn on the captions; compare them with the full audio track; check speaker changes and meaningful sounds.

## Code patterns

The scenario is given above. Code alone is not enough to test media, processes and semantics.
