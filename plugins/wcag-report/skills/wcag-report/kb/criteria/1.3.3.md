# 1.3.3 Sensory Characteristics

WCAG 2.2 · Level **A**

A practical summary in our own words; the exact obligations are set by the normative text and its definitions.

## Applicability

Instructions refer to shape, color, position, orientation or sound.

## What is required

Do not base instructions on a sensory characteristic alone.

## How to test

1. Find instructions such as "on the right", "round", "after the tone".
2. Check that a text or other non-sensory cue is present.

**Expected result:** Do not base instructions on a sensory characteristic alone. All applicable states and normative exceptions have been checked.

**Fails when:** A task asks the user to press "the round element on the right" without naming its purpose.

## How to fix

Add an accessible name and a meaningful cue to the instruction.

## Example

**Before:** "Press the green circle."

**After:** "Press 'Start recording'"; the color remains an additional cue.

## Exceptions and false positives

Color is also checked under 1.4.1; common spatial phrases are judged by whether the instruction can be understood without the sensory characteristic.

## Automation and evidence

A tool can collect candidates and measurements; the verdict depends on applicability, content, exceptions and observed behavior. The absence of an automated signal is not a pass. The main conclusion requires a person to carry out the scenario, or an observed interactive run; a static DOM alone is not enough.

- URL/route, interface state, date, sign-in method and the steps tested.
- Viewport in CSS px, zoom level, input method, user agent, and assistive technologies if used.
- The specific element/media segment/process step, reproducible observations and the actual result.
- The normative condition of 1.3.3, the exceptions checked, and an explanation of the barrier to the user.
- For this test, record: Find instructions such as "on the right", "round", "after the tone"; check that a text or other non-sensory cue is present.

## Code patterns

The scenario is given above. Code alone is not enough to test media, processes and semantics.
