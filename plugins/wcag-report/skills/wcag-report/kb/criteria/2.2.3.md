# 2.2.3 No Timing

WCAG 2.2 · Level **AAA**

A practical summary in our own words; the exact obligations are set by the normative text and its definitions.

## Applicability

Events and activities with a time limit; AAA.

## What is required

Timing must not be an essential part of the activity, except for non-interactive synchronized media and real-time events.

## How to test

1. Check every process and session expiry.
2. Separate real-time events from artificial timers.

**Expected result:** Timing must not be an essential part of the activity, except for non-interactive synchronized media and real-time events. All applicable states and normative exceptions have been checked.

**Fails when:** A task requires ordinary input to be completed within a fixed time, and no exception applies.

## How to fix

Remove the time dependency from ordinary operations.

## Example

**Before:** Filling in an application is limited to five minutes.

**After:** The application stays available with no timer.

## Exceptions and false positives

The AAA conditions are stricter than 2.2.1; an extension mechanism by itself does not substitute for the absence of a time dependency.

## Automation and evidence

A tool can collect candidates and measurements; the verdict depends on applicability, content, exceptions and observed behavior. The absence of an automated signal is not a pass. The main conclusion requires a person to carry out the scenario, or an observed interactive run; a static DOM alone is not enough.

- URL/route, interface state, date, sign-in method and the steps tested.
- Viewport in CSS px, zoom level, input method, user agent, and assistive technologies if used.
- The specific element/media segment/process step, reproducible observations and the actual result.
- The normative condition of 2.2.3, the exceptions checked, and an explanation of the barrier to the user.
- For this test, record: Check every process and session expiry; separate real-time events from artificial timers.

## Code patterns

The scenario is given above. Code alone is not enough to test media, processes and semantics.
