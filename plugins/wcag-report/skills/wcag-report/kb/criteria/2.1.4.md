# 2.1.4 Character Key Shortcuts

WCAG 2.2 · Level **A**

A practical summary in our own words; the exact obligations are set by the normative text and its definitions.

## Applicability

The shortcut consists only of letters (including upper- and lower-case letters), numbers, punctuation or symbol characters.

## What is required

Provide a way to turn it off, to remap it to include a non-printable key, or to make it active only when the relevant component has focus.

## How to test

1. Type ordinary text and use voice input.
2. Find the settings.
3. Check the scope in which the shortcuts are active.

**Expected result:** Provide a way to turn it off, to remap it to include a non-printable key, or to make it active only when the relevant component has focus. All applicable states and normative exceptions have been checked.

**Fails when:** The letter "g" deletes a record globally and cannot be turned off or remapped.

## How to fix

Use a modifier key or settings, or limit the action to when the component has focus.

## Example

**Before:** The character "d" deletes the selected note from anywhere.

**After:** The shortcut can be remapped to a combination with a modifier key.

## Exceptions and false positives

Combinations with non-printable keys, and character-key commands that work only in a focusable component while it has focus, are assessed with these conditions in mind.

## Automation and evidence

A tool can collect candidates and measurements; the verdict depends on applicability, content, exceptions and observed behavior. The absence of an automated signal is not a pass. The main conclusion requires a person to carry out the scenario, or an observed interactive run; a static DOM alone is not enough.

- URL/route, interface state, date, sign-in method and the steps tested.
- Viewport in CSS px, zoom level, input method, user agent, and assistive technologies if used.
- The specific element/media segment/process step, reproducible observations and the actual result.
- The normative condition of 2.1.4, the exceptions checked, and an explanation of the barrier to the user.
- For this test, record: Type ordinary text and use voice input; find the settings; check the scope in which the shortcuts are active.

## Code patterns

The scenario is given above. Code alone is not enough to test media, processes and semantics.
