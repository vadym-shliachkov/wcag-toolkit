# 2.1.3 Keyboard (No Exception)

WCAG 2.2 · Level **AAA**

A practical summary in our own words; the exact obligations are set by the normative text and its definitions.

## Applicability

All functionality; AAA.

## What is required

All functionality is operable through a keyboard interface, with no exception for path-dependent input. Specific timings for individual keystrokes are not required.

## How to test

1. Repeat the operations with the keyboard, including drawing and moving functions.

**Expected result:** All functionality is operable through a keyboard interface, with no exception for path-dependent input. Specific timings for individual keystrokes are not required. All applicable states and normative exceptions have been checked.

**Fails when:** In an AAA profile, an editor requires drawing a path with the mouse, with no keyboard alternative.

## How to fix

Provide a keyboard way to produce an equivalent result.

## Example

**Before:** A line can be drawn only with a pointer.

**After:** The coordinates of its points can be set with the keyboard.

## Exceptions and false positives

The 2.1.1 exception for an essential path does not apply here; do not require AAA when assessing AA.

## Automation and evidence

A tool can collect candidates and measurements; the verdict depends on applicability, content, exceptions and observed behavior. The absence of an automated signal is not a pass. The main conclusion requires a person to carry out the scenario, or an observed interactive run; a static DOM alone is not enough.

- URL/route, interface state, date, sign-in method and the steps tested.
- Viewport in CSS px, zoom level, input method, user agent, and assistive technologies if used.
- The specific element/media segment/process step, reproducible observations and the actual result.
- The normative condition of 2.1.3, the exceptions checked, and an explanation of the barrier to the user.
- For this test, record: Repeat the operations with the keyboard, including drawing and moving functions.

## Code patterns

The scenario is given above. Code alone is not enough to test media, processes and semantics.
