# 1.3.2 Meaningful Sequence

WCAG 2.2 · Level **A**

A practical summary in our own words; the exact obligations are set by the normative text and its definitions.

## Applicability

The reading order affects meaning.

## What is required

Ensure a programmatically determinable sequence that preserves meaning.

## How to test

1. Read the DOM order without CSS.
2. Compare it with the visual steps.
3. Check responsive rearrangements.

**Expected result:** Ensure a programmatically determinable sequence that preserves meaning. All applicable states and normative exceptions have been checked.

**Fails when:** The answer is read out before the question, so the relationship between them is lost.

## How to fix

Order the DOM by meaning; build the visual layout without changing the meaningful sequence.

## Example

**Before:** An instruction reads as step 3, step 1, step 2.

**After:** The DOM keeps the order in which the steps are performed.

## Exceptions and false positives

Several correct sequences are acceptable. A difference between the visual order and the DOM order is not enough on its own.

## Automation and evidence

A tool can collect candidates and measurements; the verdict depends on applicability, content, exceptions and observed behavior. The absence of an automated signal is not a pass. The main conclusion requires a person to carry out the scenario, or an observed interactive run; a static DOM alone is not enough.

- URL/route, interface state, date, sign-in method and the steps tested.
- Viewport in CSS px, zoom level, input method, user agent, and assistive technologies if used.
- The specific element/media segment/process step, reproducible observations and the actual result.
- The normative condition of 1.3.2, the exceptions checked, and an explanation of the barrier to the user.
- For this test, record: Read the DOM order without CSS; compare it with the visual steps; check responsive rearrangements.

## Code patterns

The scenario is given above. Code alone is not enough to test media, processes and semantics.
