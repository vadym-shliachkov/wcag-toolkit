# 4.1.1 Parsing — historical note

**Not a current WCAG 2.2 success criterion.** [Its entry in WCAG 2.2](https://www.w3.org/TR/WCAG22/#parsing). In the current edition of [WCAG 2.1](https://www.w3.org/TR/WCAG21/#parsing), a note says the criterion is to be considered satisfied for HTML/XML.

Incomplete tags, nesting, duplicate attributes and duplicate IDs are useful to detect as technical signals. For a 2.2 report, establish the actual loss of accessibility and the normative basis for it that is in force. For example: two fields have the same ID, so the visible label became associated with the other field and the intended field lost its accessible name. Check [1.3.1](1.3.1.md) and [4.1.2](4.1.2.md) against the observed result. If a duplicate ID changes nothing for accessibility, it remains a markup defect, not a confirmed WCAG 2.2 failure.
